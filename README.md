# shatabdi-gaya

Website for Shatabdi Public School, Gaya — built with Next.js (App Router), React and Tailwind CSS.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm run start` — serve the production build

## Structure

- `app/` — routes (home, about, academics, admissions, campus, contact, legal pages), sitemap and robots
- `components/` — shared UI (header, footer, gallery, enquiry form, testimonials, ...)
- `lib/` — site config and fonts
- `public/` — optimized images and logos
- `originals/` — original source photos
- `static-site/` — earlier static HTML version of the site
